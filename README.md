# U2-Net 在边界模糊的肾脏 B 超图像分割中的应用

## 1. 简介

将 U2-Net-lite 应用于肾脏 B 超图像分割，并与 U-Net
基线模型进行对比。U2-Net 最初用于显著性目标检测，其嵌套 U
型结构能够结合局部细节与较大范围的上下文信息，这里尝试利用这一特点处理医学图像中的目标边界。

## 2. 模型结构

U2-Net 整体采用 U 型编码器---解码器结构，并在内部嵌套更小的 U 型结构。

-   **RSU 模块**：为类似于小的UNet模块，用于 Encoder1--Encoder4 和
    Decoder1--Decoder4，在模块内部进行卷积、下采样、上采样和特征融合，以提取多尺度特征。
-   **RSU-4F 模块**：用于更深层的 Encoder5、Encoder6 和
    Decoder5，以膨胀卷积代替下采样与上采样，在较低分辨率下扩大感受野并保留上下文信息。
-   **侧输出与融合**：多个解码阶段及深层编码器的输出经过通道调整和上采样，统一到原图尺寸后进行拼接，再通过
    1×1 卷积生成预测结果。

## 3. 代码与训练重点

### 数据集与预处理

-   数据集：`kidney_data`，共 4586 张肾脏 B 超图像，尺寸为 256×256。
-   划分：3210 张训练图像、1376 张测试图像；每张图像对应一张单通道
    mask。
-   训练预处理：随机上下翻转，并进行标准化。
-   验证/测试预处理：统一尺寸并进行标准化。

### 训练配置

-   训练轮数：30 epochs
-   Batch size：4
-   优化器：AdamW
-   学习率调度：学习率预热后采用余弦衰减
-   混合精度：使用梯度缩放器辅助训练

### 实现关注点

-   自定义 **RSU** 和 **RSU-4F** 模块，并组合成 U2-Net 编码器---解码器。
-   通过多层侧输出和特征融合生成最终分割结果。

## 4. 实验结果

记录最佳结果如下：

  模型             Dice   mean-IoU    每轮训练时间   参数量
  ------------- ------- ---------- --------------- --------
  U2-Net-lite     0.975      97.1%   约 2 分 50 秒     1.2M
  U-Net-32        0.952      95.5%   约 1 分 15 秒     4.3M

在本实验中，U2-Net-lite 的 Dice 和 mean-IoU
更高，参数量也更少；但每轮训练耗时约为 U-Net-32 的两倍。其原因可能包括
RSU
模块内部的多次特征处理、上采样和特征拼接带来的额外计算与内存访问开销。

## 5. U2-Net 的优点

-   **多尺度特征提取**：嵌套 U 型结构结合局部细节和较大范围的语义信息。
-   **有利于边缘与细小区域**：多层特征融合有助于保留目标轮廓和局部细节。
-   **深度监督**：多个层级的侧输出参与训练，可为不同深度的特征提供监督信号。

## 6. 局限与改进方向

-   **数据集难度有限**：当前数据集目标较明确，尚不能充分体现边界模糊、结构复杂等困难场景下的优势。
-   **医学任务适配仍需验证**：U2-Net
    最初面向显著性目标检测，迁移到医学图像分割时仍需针对任务进行调试和验证。
-   **实验范围有限**：当前实验仅涉及二维单目标分割，尚未验证多器官或三维分割任务。

后续可在边界更模糊、结构更复杂的数据集上进行测试，并进一步探索模型结构调整、注意力机制、三维卷积及多模态信息融合。
